Bagdja no es un monolito. Es un **ecosistema modular basado en servicios**.

---

### 🌐 Ecosistema público

```txt
bagdja.com          → Landing principal

porto.bagdja.com    → Escaparate de portafolios
platform.bagdja.com → Centro de documentación
```

---

### ⚙️ Infraestructura central

```txt
console.bagdja.com         → Panel de control del desarrollador

auth.service.bagdja.com    → Identidad y SSO (fuente de verdad)

event.bagdja.com           → Capa de comunicación basada en eventos

assets.bagdja.com          → Almacenamiento de archivos y medios
```

---

## 🔐 La identidad como núcleo

Bagdja se construye con el principio:

> **La identidad es la base de todo**

Todas las aplicaciones están conectadas a través de:

```txt
app_id → identidad → acceso → monetización
```

Lo que significa:
- 1 usuario = puede acceder a todas las aplicaciones
- 1 inicio de sesión = todo el ecosistema
- 1 identidad = todas las suscripciones

## ⚡ Experiencia del desarrollador

### 🔌 Integración API-First

Bagdja está diseñado para facilitar la integración a través de APIs REST estándar pero potentes.

#### 🔐 Autenticación (SSO e Identidad)

Solo una solicitud untuk verifikasi identitas pengguna di seluruh ekosistem.

```javascript
// Iniciar sesión de usuario a través de Bagdja Auth
const response = await fetch('https://auth.service.bagdja.com/auth/login', {
  method: 'POST',
  headers: { 
    'x-api-key': 'your-app-key',
    'Content-Type': 'application/json' 
  },
  body: JSON.stringify({
    username: 'johndoe',
    password: 'securepassword'
  })
});

const { access_token, user } = await response.json();
```

#### 📡 Ecosistema basado en eventos

Conecte su aplicación con otros servicios a través de la difusión de eventos en tiempo real.

```javascript
// Difundir evento a todos los suscriptores
await fetch('https://event.bagdja.com/broadcast', {
  method: 'POST',
  headers: { 
    'x-api-key': 'your-app-key',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    orgId: '123e4567-e89b-12d3-a456-426614174000',
    appId: 'my-app-service',
    eventName: 'user.registered',
    data: { userId: 'user-123', email: 'test@example.com' },
    signature: 'base64-encoded-signature'
  })
});
```
