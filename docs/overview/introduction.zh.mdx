```txt
console.bagdja.com         → 开发者控制台

event.bagdja.com           → 事件驱动的通信层

assets.bagdja.com          → 文件与媒体存储
```

---

## 🔐 以身份为核心

Bagdja 构建的原则是：

> **身份是一切的基础**

所有应用都通过以下方式连接：

```txt
app_id → 身份 → 访问权限 → 变现
```

这意味着：
- 1 个用户 = 可以访问所有应用
- 1 次登录 = 整个生态系统
- 1 个身份 = 所有订阅

## ⚡ 开发者体验

### 🔌 API 优先集成

Bagdja 旨在通过标准且强大的 REST API 简化集成。

#### 🔐 身份验证 (SSO 与身份)

只需一个请求即可在整个生态系统中验证用户身份。

```javascript
// 通过 Bagdja Auth 登录用户
const response = await fetch('https://auth.service.bagdja.com/auth/login', {
  method: 'POST',
  headers: { 
    'x-api-key': 'your-app-key',
    'Content-Type': 'application/json' 
  },
  body: JSON.stringify({
    username: 'johndoe',
    password: 'securepassword'
  })
});

const { access_token, user } = await response.json();
```

#### 📡 事件驱动生态系统

通过实时事件广播将您的应用程序与其他服务连接起来。

```javascript
// 向所有订阅者广播事件
await fetch('https://event.bagdja.com/broadcast', {
  method: 'POST',
  headers: { 
    'x-api-key': 'your-app-key',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    orgId: '123e4567-e89b-12d3-a456-426614174000',
    appId: 'my-app-service',
    eventName: 'user.registered',
    data: { userId: 'user-123', email: 'test@example.com' },
    signature: 'base64-encoded-signature'
  })
});
```
